# Portfólio | Andriele Martins

Bem-vindo ao meu portfólio.

Este projeto foi desenvolvido para apresentar minhas habilidades, projetos e minha evolução como desenvolvedora. O objetivo é reunir em um único lugar os trabalhos que desenvolvi, as tecnologias que estudo e as formas de contato.

## Sobre

Sou estudante de Desenvolvimento de Sistemas e tenho grande interesse pela área de tecnologia, especialmente desenvolvimento web e programação. Busco constantemente aprender novas tecnologias e criar projetos que fortaleçam minhas habilidades práticas.

## Funcionalidades

* Página inicial responsiva
* Seção "Sobre"
* Exibição de projetos
* Lista de habilidades
* Área de contato
* Interface moderna
* Animações em JavaScript

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em seu navegador.
